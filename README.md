# Markdown Viewer - 마크다운 편집기

로컬에서 안전하게 사용할 수 있는 간편한 마크다운 편집기입니다. 기기에 저장된 마크다운 또는 텍스트 파일을 열거나, 파일을 화면에 끌어다 놓거나, 포함된 예제를 편집해 보세요. 입력하는 즉시 미리보기가 갱신됩니다.

## 주요 기능

- 표, 작업 목록, 취소선을 포함한 GitHub Flavored Markdown(GFM)을 지원합니다.
- 미리보기에 표시하기 전에 HTML을 정화합니다.
- 편집기와 미리보기를 나란히 보여 주며, 작은 화면에서는 보기 전환 기능을 제공합니다.
- 로컬 파일 열기와 끌어다 놓기를 지원합니다. 번역을 설정하고 동의하지 않으면 문서는 기기 밖으로 전송되지 않으며, 앱은 문서를 저장하지 않습니다.
- HTTPS 번역 서비스 주소를 설정하면 한국어가 아닌 문서를 한국어로 자동 번역합니다. 원문은 편집기에 유지되며 미리보기에서 원문과 번역을 전환할 수 있습니다.

## 로컬에서 실행하기

Node.js 20 이상이 필요합니다.

```sh
npm install
npm run dev
```

Vite가 출력하는 로컬 URL을 브라우저에서 여세요. 프로덕션 빌드를 만들거나 마크다운 렌더링 테스트를 실행하려면 다음 명령을 사용하세요.

```sh
npm run build
npm test
```

마크다운 렌더링에는 GFM을 활성화한 `marked`를 사용합니다. 렌더링된 HTML은 미리보기에 삽입되기 전에 DOMPurify를 거칩니다.

## GitHub Pages 배포

`main` 브랜치에 변경 사항을 푸시하면 GitHub Actions가 테스트와 Vite 빌드를 실행하고 GitHub Pages에 배포합니다. 저장소 설정의 **Settings > Pages > Build and deployment > Source**를 **GitHub Actions**로 지정해야 합니다. 이 저장소의 기본 배포 주소는 [https://uicheol-it.github.io/Markdown-Viewer/](https://uicheol-it.github.io/Markdown-Viewer/)입니다. 사용자 지정 도메인을 사용한다면 Pages에 도메인을 등록하고 저장소의 Actions 변수 `VITE_BASE_PATH`를 `/`로 설정하세요. 기본값은 저장소 Pages 경로(`/<저장소 이름>/`)이며, 로컬 개발·미리보기의 기본값은 `/`입니다.

## 한국어 자동 번역 설정과 개인정보

번역은 기본적으로 비활성화되어 있으며, 앱은 번역 서비스에 연결하지 않습니다. 사용하려면 미리보기의 **번역 설정**에서 HTTPS 번역 서비스 주소를 입력하세요. 서비스는 브라우저에서 직접 호출할 수 있도록 CORS를 허용해야 하며 다음 API 형식을 구현해야 합니다.

- 요청: `POST` JSON `{ "text": "<Markdown>", "source": "auto", "target": "ko" }`
- 응답: JSON `{ "translatedText": "<번역된 Markdown>" }`

번역을 시작하기 전에 서비스 주소별로 한 번 동의해야 합니다. 동의한 뒤에는 설정한 서비스에 문서 전체가 전송되어 자동 번역됩니다. 코드 블록, 인라인 코드, 링크 주소와 주요 Markdown 표식은 보존을 시도하며, 편집기의 원문은 변경하지 않습니다. 번역 결과를 서비스가 손상한 경우 결과를 거부합니다. 번역 서비스는 문서 전체를 처리할 수 있는 요청 크기 제한을 지원해야 합니다. 주소와 동의 상태는 브라우저의 로컬 저장소에 저장되며 API 키나 자격 증명은 앱에 입력하거나 저장하지 않습니다. 서비스를 직접 운영하거나 신뢰하는 서버 측 프록시를 사용하고, 필요한 외부 API 자격 증명은 그 서버에만 보관하세요. 서비스의 개인정보 처리 방침과 문서의 민감 정보를 확인한 뒤 사용하세요.
